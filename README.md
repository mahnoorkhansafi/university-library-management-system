# University Library Management System (ULMS)

## Project Overview & Scope
ULMS is an integrated web platform designed to automate core library operations including cataloging, member registration, book issuing/returning, fine calculation, and online catalog searching (OPAC).

## Objectives
1. Automate inventory management and manual catalog search.
2. Provide 24/7 online book reservations for students and faculty.
3. Automatically track due dates and accurately compute overdue fines.

## Assumptions & Constraints
* **Assumptions:** Users have active institutional email accounts.
* **Constraints:** 8-week timeline; open-source technology stack.
